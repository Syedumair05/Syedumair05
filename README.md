# 🚀 Syed Umair Ahmed – Portfolio Website

A modern, high-performance personal portfolio website built with **React**, **Vite**, **Bootstrap**, and **Framer Motion**, featuring glassmorphism design, theme customization (Dark/Light mode), dynamic interactive project showcases, and direct resume access.

🔗 **Live Demo (Vercel)**: [https://syed-umair-ahmed-portfolio.vercel.app](https://syed-umair-ahmed-portfolio.vercel.app) *(or your Vercel deployment URL)*

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 19 + Vite
- **UI & Styling**: Bootstrap 5 + Custom CSS (Glassmorphism & Gradients)
- **Animations**: Framer Motion
- **Icons**: React Icons (FontAwesome & Simple Icons)
- **Deployment**: Vercel

---

## ✨ Key Features

- **Hero Section**: Dynamic typing roles, primary **Download Resume** CTA button, project navigation, and social links.
- **Featured Software Projects**: 6 interactive project cards showing category badges, descriptions, live demo & GitHub repository links, and full tech stack tags (Git/GitHub, Python, Database Fundamentals, OOP, Data Structures & Algorithms, React, TypeScript).
- **Work Experience & Internships**: Highlights roles at FlyRank AI and Alfido Tech.
- **Education & Certifications**: Detailed academic background and verified credentials.
- **Dark / Light Mode**: Seamless theme toggling.
- **Responsive Layout**: Optimized across all device screen sizes.

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Syedumair05/Syedumair05.git
   cd Syedumair05
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the dev server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🌐 Deployment on Vercel

This repository is configured with `vercel.json` for automatic deployments:
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **SPA Rewrites**: Redirects all routes to `index.html`

Every push to the `main` branch automatically triggers a deployment on Vercel.
